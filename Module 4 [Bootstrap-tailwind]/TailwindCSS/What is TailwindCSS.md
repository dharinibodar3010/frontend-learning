# What is TailwindCSS?

1. Tailwind CSS is a utility-first CSS framework used to create responsive and modern web applications.

2. It provides predefiend utitlity classes that help developers build user interfaces quickly without writing much custom css.

***
## Features: 

1. utility-first approach
2. responsive design
3. faster
4. reusable classes
5. customizable 

***

### Example: 
```
<button class="bg-blue-500 text-white px-4 py-2 rounded"> click me </button>

```
