## Error Message:
ReferenceError: document is not defined

## Explanation:

This error means that JavaScript cannot find the `document` object.  
The `document` object is provided by the browser and is used to access HTML elements using DOM methods.  
This error usually occurs when we run browser-based JavaScript code using Node.js instead of running it in a browser.  
To fix this error, run the JavaScript code inside an HTML file in the browser or avoid using DOM methods in Node.js.


## Fix:

Run the JavaScript file using an HTML file:

```html
<script src="script.js"></script>
